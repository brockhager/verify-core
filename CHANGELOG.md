# Changelog

## 0.1.0 - 2026-10-10
First version. Registry server (profiles, signed claims, key rotation, public list, lookup, did.json), pilot command line tool, and browser extension popup. Platforms: X, LinkedIn, GitHub, Facebook, Instagram.
Known limits: pilot-only unencrypted key file, no recovery phrase, JSON file storage, no rate limiting, claim backdating (Q24), extension not yet tested in a browser.
